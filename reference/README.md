# Notebook de referencia

`gaia_anguita_original.ipynb` es una copia sin modificaciones del notebook facilitado por el Dr. Timo Anguita, según la información aportada por Matías Almonacid Mellado. Se conserva para identificar el punto de partida del trabajo.

El desarrollo que utiliza la copia local de los datos está en `notebooks/gaia_lens_components.ipynb` y `src/lens_analysis.py`. La reproducción de este proyecto no requiere ejecutar el notebook de referencia.

El notebook original utiliza `astroquery` y `astropy` y consulta el archivo Gaia. Sus salidas corresponden a la ejecución guardada en el archivo original; no son los resultados de la implementación actual.
